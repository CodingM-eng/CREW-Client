# CREW Network Çok Oyunculu Sunucusu (`oyna.crewnetwork.space`)

Bu belge, CREW Client'ın resmi çok oyunculu sunucusu olan **CREW Network** (`oyna.crewnetwork.space`) entegrasyonunu, oyun mekaniklerini ve sunucu özelliklerini açıklamaktadır.

---

## 1. Sunucu Bilgileri

- **Sunucu Adresi:** `oyna.crewnetwork.space`
- **Desteklenen Sürüm:** Minecraft Java Edition 1.21.11
- **Tür:** Rekabetçi Hayatta Kalma (SMP), Klan Savaşları ve PvP
- **Doğrudan Bağlantı:** CREW Client başlatıcısındaki ana ekranda yer alan *"CREW Network'e Katıl"* butonu ile doğrudan bağlanabilirsiniz.

---

## 2. Temel İlkeler ve Oynanış

1. **Adil Oyun (P2W Karşıtı):**
   CREW Network üzerinde gerçek parayla oyun içi üstünlük sağlayan eşyalar satılmaz. Tüm rütbeler, eşyalar ve ekonomi oyundaki emekle elde edilir.
2. **PvP Optimizasyonu:**
   Vuruş gecikmelerini en aza indiren özel ağ yönlendirmeleri, stabil 20 TPS sunucu performansı ve optimize edilmiş vuruş kayıt (hit-registration) mekaniği.
3. **Güvenli Ticaret:**
   Oyuncular arası takaslarda dolandırıcılığı önleyen çift taraflı onay pencereleri.

---

## 3. Temel Sunucu Komutları

| Komut | Açıklama |
|---|---|
| `/spawn` | Sunucu başlangıç noktasına (Spawn) ışınlar. |
| `/sethome [isim]` | Bulunduğunuz konumu ev olarak kaydeder. |
| `/home [isim]` | Kaydettiğiniz evinize ışınlar. |
| `/tpa <oyuncu>` | Bir oyuncuya ışınlanma isteği gönderir. |
| `/tpaccept` | Gelen ışınlanma isteğini kabul eder. |
| `/claim` | Bulunduğunuz araziyi koruma altına alır (Claim). |
| `/trust <oyuncu>` | Arazinize arkadaşınızı ekler. |
| `/balance` / `/bal` | Mevcut oyun içi bakiyenizi görüntüler. |
| `/pay <oyuncu> <miktar>` | Başka bir oyuncuya para transfer eder. |
| `/baltop` | Sunucunun en zengin oyuncularını listeler. |
| `/trade <oyuncu>` | Oyuncular arası güvenli takas menüsünü açar. |
| `/rules` | Sunucu kurallarını listeler. |
