Dokümantasyon & Rehberler

CREW Client kurulumu, hesap güvenliği, mod mimarisi ve sorun giderme yönergeleri.

1. Kurulum Rehberi

CREW Client, Windows 10 ve Windows 11 64-bit sistemler için optimize edilmiş, taşınabilir (portable) ve yüksek performanslı bir Minecraft başlatıcısıdır.

Taşınabilir Yapı: CREW Client geleneksel karmaşık kurulum sihirbazları gerektirmez. Tek bir crew-client.exe dosyasını istediğiniz klasöre taşıyarak doğrudan çalıştırabilirsiniz.

Adım Adım Kurulum

  • 1. İndirme: İndirme sayfasından en güncel crew-client.exe ikili dosyasını indirin.
  • 2. Klasör Konumu: İndirilen dosyayı tercihen C:\Oyunlar\CREW-Client\ veya kullanıcı ana dizininiz gibi yazma iznine sahip olduğunuz güvenli bir dizine yerleştirin.
  • 3. Ön Koşullar: Başlatıcının gömülü web bileşenleri için Windows 10/11 ile birlikte gelen standart Microsoft Edge WebView2 Runtime bileşeni gereklidir (güncel sistemlerde varsayılan olarak mevcuttur).
  • 4. Başlatma: Dosyaya çift tıklayarak CREW Client'ı başlatın. İlk açılışta gerekli yapılandırma dosyaları yerel olarak %APPDATA%\.crew dizininde oluşturulur.

Windows SmartScreen Uyarısı Hakkında

Yeni bir sürüm yayınlandığında Windows SmartScreen "Windows bilgisayarınızı korudu" uyarısı gösterebilir. Bu durum, açık kaynaklı yeni sürümlerin Microsoft güven veritabanında henüz yeterli indirme hacmine ulaşmamış olmasından kaynaklanır.

Nasıl Geçilir? Ekranda çıkan "Ek Bilgi" (More Info) bağlantısına tıklayın ve ardından "Yine de çalıştır" (Run anyway) butonuna basın. CREW Client'ın kaynak kodları tamamen açık olup SHA-256 sağlama toplamı ile doğrulanabilir.

2. Microsoft Hesabı Ekleme & Güvenlik

CREW Client, resmi Minecraft Java Edition sunucularına bağlanabilmeniz için Microsoft OAuth 2.0 protokolünü kullanır.

Oturum Açma Adımları

  • Başlatıcı arayüzünde sol menünün alt kısmında yer alan "Hesap Ekle" veya "Microsoft ile Giriş Yap" butonuna tıklayın.
  • Açılan resmi Microsoft oturum penceresinde Minecraft Java Edition lisansına sahip Microsoft hesabınızın e-posta ve şifresini girin.
  • İki adımlı doğrulama (2FA) kullanıyorsanız telefonunuza gelen onay kodunu girin.
  • Oturum açma tamamlandığında oyuncu adınız ve karakter görünümünüz (skin) başlatıcı arayüzünde otomatik olarak görünecektir.
%100 Hesap Güvenliği:
  • Şifreniz CREW Client, CREW Network veya herhangi bir üçüncü taraf sunucu tarafından asla görülmez, kaydedilmez ve iletilmez.
  • Oturum açma işlemi doğrudan Microsoft'un resmi login.live.com sunucuları üzerinde gerçekleşir.
  • Oturum belirteçleri (refresh tokens) yerel bilgisayarınızda Windows DPAPI (Data Protection API) ve güvenli anahtarlık mekanizmalarıyla şifrelenmiş olarak saklanır.

3. Mod Kurulumu & Yönetimi (Fabric vs Native)

CREW Client, oyunculara hem mod ekosisteminin zenginliğini hem de yerel motorun maksimum performansını sunan iki farklı mimari yaklaşımı destekler.

Önemli Mimari Ayrımı: CREW Client içerisindeki Minecraft Java Fabric ortamı ile CREW Native Engine birbirinin alternatifi değil, farklı amaçlara hizmet eden iki ayrı teknolojidir.

☕ Java Edition (Fabric Loader)

Minecraft 1.21.11 / 26.3 sürümleri için standart Java Sanal Makinesi (JVM) ortamı.

  • Sodium, Iris Shaders, Lithium gibi popüler Java modlarını (.jar) tam destekler.
  • Mod Menüsü ve profil yöneticisi ile uyumludur.
  • Geniş mod ekosistemi ve özel shader paketleri için idealdir.

⚡ CREW Native Engine (Rust)

Açık kaynak Horizon tabanlı, doğrudan makine koduna derlenen yerel motor.

  • Sıfır Java Sanal Makinesi yükü ve sıfır GC (Garbage Collection) takılması.
  • Mikrosaniye seviyesinde giriş gecikmesi ve ultra-yüksek kare hızı.
  • Önemli: Doğrudan Java .jar modlarını çalıştırmaz; yerel Rust/C++ eklentilerini kullanır.

Fabric Ortamına Mod Ekleme

  1. İstediğiniz Fabric uyumlu modu (örneğin Sodium veya Mod Menu .jar) Modrinth veya CurseForge üzerinden indirin.
  2. CREW Client arayüzünde profil detaylarına gidin ve "Mod Klasörünü Aç" butonuna tıklayın (veya doğrudan %APPDATA%\.crew\instances\<profil>\mods klasörüne gidin).
  3. İndirdiğiniz .jar dosyalarını bu klasöre yapıştırın.
  4. Oyunu başlattığınızda modlar otomatik olarak yüklenecektir.

4. Güncelleme Sistemi & Bütünlük Doğrulama

CREW Client, kullanıcı deneyimini ve sistem kararlılığını korumak için çok katmanlı bir güncelleme ve bütünlük denetim mimarisi uygular.

Upstream Horizon Senkronizasyonu

CREW Client, temel aldığı açık kaynak horizon-rust/horizon projesinin güncellemelerini arka planda sürekli olarak takip eder. Ancak sistem kararlılığı için upstream kodları ham olarak istemciye doğrudan yazılmaz; CREW mühendislik ekibi tarafından otomatik testlerden geçirilir, Türkçeleştirilir ve doğrulanmış sürüm olarak yayınlanır.

SHA-256 Sağlama Toplamı Doğrulama

İndirdiğiniz dosyanın orijinal CREW yayını olduğunu ve araya hiçbir yabancı kod girmediğini Windows üzerinde kolayca doğrulayabilirsiniz:

PowerShell ile:

Get-FileHash .\crew-client.exe -Algorithm SHA256

Komut İstemi (CMD) ile:

certutil -hashfile crew-client.exe SHA256

Çıkan özet değerinin resmi indirme sayfamızdaki SHA-256 hash değeri ile birebir eşleştiğini teyit edin.

5. Sık Karşılaşılan Hatalar & Çözümleri

Oyun sırasında veya başlatıcı açılışında karşılaşabileceğiniz sorunlar ve adım adım çözüm yöntemleri:

EXCEPTION_ACCESS_VIOLATION veya OpenGL Sürücü Çökmesi

Özellikle NVIDIA GeForce / GTX serisi ekran kartlarında oyun açılırken veya hibrit ardışık düzen başlatılırken çökme yaşanıyorsa:

Çözüm:
  1. NVIDIA Denetim Masası'nı açın -> 3D Ayarlarının Yönetilmesi -> Program Ayarları sekmesinden crew-client.exe ve javaw.exe dosyalarını ekleyin.
  2. Tercih edilen grafik işlemciyi "Yüksek Performanslı NVIDIA İşlemcisi" olarak ayarlayın.
  3. GeForce Experience veya NVIDIA web sitesi üzerinden en güncel Game Ready grafik sürücüsünü yükleyin.
  4. Başlatıcı ayarlarından "Güvenli Render Modu" (Vanilla Fallback) seçeneğini aktif hale getirin.
Java Runtime Environment (JRE) Bulunamadı

Minecraft Java profili başlatılırken Java 21 çalışma zamanı bulunamadı uyarısı alınıyorsa:

Çözüm: Minecraft 1.21.11 sürümü Java 21 (64-bit) gerektirir. Eclipse Temurin 21 veya Microsoft OpenJDK 21 yükleyin. Sistem ortam değişkenlerinde JAVA_HOME değerinin tanımlı olduğundan emin olun.
Microsoft Giriş Penceresi Açılmıyor / Beyaz Ekran

Giriş butonuna tıklandığında kimlik doğrulama penceresi boş veya tepkisiz kalıyorsa:

Çözüm: Bilgisayarınızda Microsoft Edge WebView2 çalışma zamanı eksik veya hasarlı olabilir. Resmi Microsoft web sitesinden WebView2 Evergreen Bootstrapper indirip yeniden kurun ve Windows'u yeniden başlatın.
Eksik DLL Hatası (VCRUNTIME140.dll veya MSVCP140.dll)

Başlatıcı açılırken sistemde Visual C++ kütüphanelerinin eksik olduğunu belirten bir Windows iletişim kutusu açılıyorsa:

Çözüm: Microsoft'un resmi sitesinden Visual C++ Redistributable 2015-2022 (x64) paketini indirip kurun.

7. Sıkça Sorulan Sorular (SSS)

CREW Client tamamen ücretsiz mi?

Evet. CREW Client açık kaynaklıdır ve tüm oyuncular için tamamen ücretsiz olarak sunulur. Hiçbir gizli ücret, abonelik veya oyun içi mikro ödeme içermez.

CREW Client kullanmak sunucularda ban sebebi midir?

Kesinlikle hayır. CREW Client hile (cheat/hack), makro veya haksız avantaj sağlayan yazılımlar içermez. Sunuculara resmi Minecraft protokolüyle bağlanır ve önde gelen PvP sunucularının kurallarına tam uyumludur.

Microsoft hesap bilgilerim güvende mi?

Evet, %100 güvendedir. Kimlik doğrulama doğrudan Microsoft'un resmi OAuth 2.0 sunucuları üzerinden yapılır. Şifreniz asla istemci veya sunucularımız tarafından okunamaz ve saklanamaz.

CREW Client ile Horizon projesi arasındaki ilişki nedir?

CREW Client, açık kaynaklı Horizon projesinin (Ludovic Marie ve topluluk katkıcıları) yenilikçi Rust altyapısını temel alır. CREW Network ekibi tarafından Türk oyuncu topluluğu için Türkçeleştirilmiş, optimize edilmiş, kararlı hale getirilmiş ve özel sunucu entegrasyonuyla zenginleştirilmiş bağımsız ve resmi bir türevidir. Orijinal yazarların açık kaynak lisanslarına (GPL/MIT) tam saygı gösterilir.

Gerçekten FPS artışı ve düşük gecikme sağlar mı?

Evet. Başlatıcı arayüzü Electron gibi ağır web motorları yerine saf Rust ve GPUI kullanır, bu sayede sistem kaynaklarını tüketmez. Java profilindeki optimize edilmiş mod paketi (Sodium, Lithium vb.) ve deneysel CREW Native Engine sayesinde belirgin FPS artışı ve stabil kare süreleri (frametime) elde edilir.
