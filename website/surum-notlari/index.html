CREW Client v2.1.0 — Kararlılık & Güvenlik Güncellemesi

İstemci: v2.1.0 Motor: v2026.10.13 Minecraft: 1.21.11 Fabric: 0.16.14
✨ Öne Çıkan Geliştirmeler
  • Sahte İstatistiklerin Kaldırılması: Eski Horizon telemetri sunucusuna (`telemetry.playhorizon.dev`) yapılan tüm bağlantılar ve gerçeği yansıtmayan sayaçlar tamamen kaldırıldı. Yalnızca şeffaf GitHub ve doğrudan Minecraft sunucu ping verileri entegre edildi.
  • Uygulama İçi Microsoft Client ID Yapılandırması: HORIZON_MSA_CLIENT_ID missing hatası giderildi. Artık ortam değişkeni olmasa dahi istemci içinden doğrudan Azure Client ID girilip auth.json dosyasına kaydedilebiliyor.
  • Demo / Çevrimdışı Profil Modu: Microsoft hesabı olmadan arayüzü ve yerel özellikleri test etmek isteyenler için 'Demo / Çevrimdışı İncele' seçeneği eklendi.
  • FPS Karşılaştırma Sistemi & Doğrulanmış Benchmark Veri Seti: Kontrollü laboratuvar koşullarında ölçülen doğrulanmış donanım profilleriyle gerçekçi FPS hesaplayıcı entegre edildi.
  • %100 Doğal Türkçe Yerelleştirme: Başlatıcı arayüzü, hata asistanı, diyalog pencereleri ve web sitesi tam Türkçe dil desteğine kavuşturuldu.
  • Doğrudan Sunucu Bağlantısı: oyna.crewnetwork.space resmi sunucusunun canlı durumu ana ekranda görüntülenir ve tek tıkla bağlanılabilir.
