CREW Client

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.

Who makes it

CREW Client is made by Ludovic Marie; reach him through lu4ovic.com (opens in a new tab). This site is developed by Anthony S of DezerX (opens in a new tab), who is responsible for it. CREW Client contains no Minecraft code, assets or data, and this site offers no game files: you need your own legally obtained copy of Minecraft: Java Edition. Minecraft is a trademark of Mojang Synergies AB.

Licences

CREW Client's original work is under the MIT licence (opens in a new tab). The fonts are Geist and Geist Mono, under the SIL Open Font License (opens in a new tab). Every asset on this site is listed in LEGAL.md.

Privacy

This site sets no cookies, has no analytics or trackers and loads nothing from third parties except GitHub. When you open a release, the server keeps a one-way hash of your IP address so that release counts each visitor once; the address itself is never stored. To show the latest releases, patch notes, links and contributors, your browser asks api.github.com and raw.githubusercontent.com for them, and avatars.githubusercontent.com for the contributors' pictures; GitHub's privacy statement (opens in a new tab) covers those requests. The launcher sends nothing unless you allow it: what it can send, and how to delete it (opens in a new tab).

Privacy policy

Do I need to buy Minecraft?

Yes. CREW Client contains no Minecraft code, assets or data. It builds its game files from your own copy of Minecraft: Java Edition 26.3, on your computer. See Install.

Is CREW Client official?

No. It is not an official Minecraft product, and it is not approved by or associated with Mojang or Microsoft. It is open source, under the MIT licence.

Is CREW Client the same as Minecraft Rust Edition?

"Minecraft Rust Edition" is a name some players use for CREW Client, because CREW Client is Minecraft: Java Edition rewritten in Rust. It is not an edition made by Mojang or Microsoft. Other projects use the name too, including a fork of CREW Client. The original is the one on this site, with its source at horizon-rust/horizon. See What CREW Client is.

Will my Forge, NeoForge or Fabric mods work?

No. Java mod jars do not run in CREW Client. CREW Client has its own mod system, and the launcher can carry over the data-and-assets part of some Java mods. See Modpacks and Mods and data packs.

Can I join public servers?

Not yet. Most public servers check that you own Minecraft, which needs a Microsoft account sign-in, and CREW Client cannot do that yet. It can join servers in offline mode, such as your own or a friend's. See Multiplayer.

When will Microsoft sign-in work?

We cannot give a date. It needs an app registration with Microsoft and an approval from Mojang that the project does not have yet. Until then, this site only describes what works today.

Can vanilla players join my CREW Client world or server?

Yes. A vanilla 26.3 client can join a CREW Client server and a CREW Client LAN world. See Multiplayer and Host a server.

Can I use my existing worlds?

Yes. Worlds from Minecraft 1.8 to 26.2 are upgraded the way vanilla upgrades them, and saves use vanilla's format. Copy your world into the game folder's saves folder, and make a backup first, as you would before opening a world in any new version.

Where are my worlds and settings?

In the game folder: ~/.local/share/horizon on Linux, ~/Library/Application Support/horizon on macOS and %APPDATA%\horizon on Windows. Updating the game never touches it.

Does it change my normal Minecraft install?

No. CREW Client only reads your Minecraft files when it prepares, and keeps what it needs in its own folder.

Why does preparing need Java 25?

Preparation runs vanilla's own data generator on your copy of the game, to read data such as every item's default components, and that is Java. It is needed for the preparation only. The game and the server themselves run without Java.

What does "100% vanilla parity" mean?

Every subsystem matches vanilla in every harness that compares it. It means 100% of what the harnesses compare, not proof that nothing else differs. See What CREW Client is and the status table.

Which systems does it run on?

Linux x86-64, macOS on Apple Silicon and Windows x64. See supported systems.

Are shader packs supported?

Not right now. They have been removed, and will come back later, written again from scratch. See Settings.

Does CREW Client collect data?

Only if you say yes, and each kind has its own switch. Everything is off by default. The one thing sent without asking is an anonymous "I'm playing" ping, for the count of how many play right now: it holds a random number made each time the game starts, the version, your OS and whether a world is open to LAN, and nothing about you. See Privacy.

How often does it update?

Often. Every change players can see is released automatically after it is merged, so new versions can come out several times a day. Each one is tested before it goes out (the game has to start and draw a world), and the launcher installs it as soon as it is out. There is one version for everyone. See Install.

What do the version numbers mean?

Since 0.2, every release has a number: 0.2.0, then 0.2.1, 0.2.2 and so on, one for each release. The game and the launcher are both on 0.2 and count on their own, so you can play CREW Client 0.2.7 with launcher 0.2.3. A bigger step, such as 0.3, is announced when it comes. Releases before 0.2 were named after the day they came out (2026.10.19.15); every 0.2 release is newer than all of them.
