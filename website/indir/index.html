Kurulum Adımları

  1. Dosyayı İndirin: Yukarıdaki butona tıklayarak crew-client.exe dosyasını bilgisayarınıza kaydedin.
  2. Başlatın: İndirilen dosyaya çift tıklayın. Kurulum gerektirmez, doğrudan taşınabilir (portable) olarak çalışır.
  3. Microsoft Hesabı ile Oturum Açın: Başlatıcı ekranında "Microsoft ile Giriş Yap" düğmesine tıklayarak Minecraft Java Edition hesabınızı bağlayın.
  4. Oyuna Başlayın: Varsayılan olarak eklenen CREW Network sunucusunu seçin ve "Oyuna Başla" ile maceraya katılın!
