Sistem Gereksinimleri

Asgari Donanım

  • İşletim Sistemi: Windows 10 (64-bit) Sürüm 1903 veya üzeri
  • İşlemci: Intel Core i3-3210 3.2 GHz / AMD A8-7600 APU 3.1 GHz
  • Bellek: 4 GB RAM
  • Grafik: Vulkan 1.2 veya DirectX 11 destekli GPU (Intel HD 4000+)
  • Disk: 2 GB boş depolama alanı

Önerilen Donanım

  • İşletim Sistemi: Windows 11 (64-bit)
  • İşlemci: Intel Core i5-10400 / AMD Ryzen 5 3600 veya üstü
  • Bellek: 8 GB - 16 GB RAM
  • Grafik: NVIDIA GeForce GTX 1660 / AMD Radeon RX 5600 XT
  • Disk: NVMe SSD depolama
